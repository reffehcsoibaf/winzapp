🔌 1. Getting started

Pairing WhatsApp

When you open WinZapp for the first time (or after disconnecting), the connection screen appears with two ways to pair:

  1. 1QR Code (default): on your phone, open WhatsApp, go to Settings > Linked devices > Link a device, and point the camera at the code shown on WinZapp's screen.
  2. 2Phone number: click Link with phone number, choose your country, type your number and click Continue. WhatsApp generates a short letter/number code — type that code on your phone, in the same place (Settings > Linked devices > Link with phone number).

Both buttons for switching between QR Code and phone number live right on the connection screen, so you can change your mind at any point before pairing.

What happens after pairing

As soon as pairing is confirmed, WinZapp starts syncing your chats. This process has two parts:

📇 Index

First, it builds the list of chats and messages — this is fast, because no media (photo, audio, video, sticker, document) is downloaded automatically at this point. This keeps the first sync light and quick.

🖼️ Media

Then, if automatic download is enabled (Settings > Storage), it fetches the most recent media a bit at a time, in the background, periodically announcing how many have been processed.
💡 Media on demand
Even with automatic download off, opening a media item manually (photo, audio, etc.) always downloads it on the spot.

If you need to pair again

WhatsApp can occasionally end the session — for example, if the phone is offline for too long, or if you remove the device manually from the phone. When this happens, WinZapp shows the same connection screen again, and the process is identical to the initial pairing.

🧭 2. Basic navigation

The chat list

When you open WinZapp, the main list shows your regular chats — individual and group — ordered most recent first. Up/down arrows move between them; Enter opens the focused chat.

Starting something new

In the main menu (press Alt), right at the top, there are three shortcuts to start something from scratch:

💬 New chat

Search by name or number among your contacts and existing chats. Also the Ctrl+N shortcut.

👥 New group

Choose a name and the participants from your saved contacts, with search.

New contact saves a first name, last name and number locally in WinZapp, so it shows up in future searches.

📦 Archived

Archived chats don't show up in the main list — they live in their own tab, with search and filters (all, unread, groups, individual). Archiving/unarchiving syncs with the phone.

🔒 Locked

A locked chat (WhatsApp's own feature) disappears completely from the list as soon as you open the app, with no manual step needed.

To reach a locked chat, type the lock code right into the main list's search box. If the code is correct, locked chats appear temporarily in the search results; opening one of them may ask for the code again, depending on how you configured that in Settings > Conversations > Locked conversations.

⚠️ Locked and archived don't coexist
WhatsApp doesn't allow a chat to be both archived and locked at the same time — if you lock an archived chat from the phone, it's automatically unarchived.

Blocked contacts

Chats with a contact you've blocked are also hidden from everything — main list and Archived — with no exception. There's no dedicated screen inside WinZapp yet to manage blocked contacts; that still has to be done through WhatsApp on the phone.

Search

The main list's search box filters by chat name. As mentioned above, typing the lock code there also temporarily reveals locked chats.

💬 3. Inside a chat

Navigating messages

Inside an open chat, the ↑ and ↓ arrows move focus between messages. When focusing a message that has media (photo, audio, video, sticker, document) or a link, pressing Tab moves focus into it — for a link, straight to the link itself; for media, to that message's action buttons.

Action buttons by message type

The buttons shown vary by the type of the focused message:

🖼️ Image, sticker, video, document

If AI is on, the first button is Describe (or Transcribe sticker), followed by Open and Save as.

🎙️ Audio

Plays with Enter on the message itself (not a separate button); if AI is on, the Transcribe button appears.

If the media hasn't been downloaded yet (automatic download off, or outside the configured window), a Download button appears instead — it downloads right away, on demand.

Replying and reacting

  1. 1With a message focused, Alt+R starts a reply to it (the typing field switches to show "replying to…").
  2. 2In groups, Alt+Shift+R replies privately — sends a direct message to the sender, quoting the group message.
  3. 3Ctrl+Shift+R opens a quick list of reaction emojis; pick one to react to the focused message, or click More emojis… to open the full picker, with search by name.

Message info

Alt+Shift+D on one of your own messages opens the sent, delivered, read and (for audio/video) played time — in a group, broken down member by member for who received and who read it.

ℹ️ More shortcuts
Copy, forward, edit, delete and several other message shortcuts are listed in full in the Keyboard shortcuts section.

🤖 4. AI: Transcriptions & Descriptions

WinZapp can use AI to transcribe audio and stickers, and describe images and videos — useful for knowing what a piece of media contains without needing to see it. Received PDFs can also be converted into accessible text.

Three AI providers can be configured — Google Gemini, OpenAI and Claude — and you don't have to pick just one: fill in the key for as many as you like. Whenever a piece of media is processed, WinZapp tries Gemini first; if it fails or isn't configured, it tries OpenAI; if that also fails or isn't configured, it tries Claude. An error only appears if none of the configured providers can process that media.

How to turn it on

  1. 1Go to Settings > Conversations tab > Transcriptions and Descriptions button.
  2. 2Check Enable AI features.
  3. 3Use a provider's button (for example, Configure Gemini) and paste its API key; just one is enough: Gemini API key (free, obtained at aistudio.google.com/apikey), OpenAI API key (platform.openai.com/api-keys), Claude API key (console.anthropic.com/settings/keys), Groq API key (free tier, console.groq.com/keys) and/or OpenRouter API key (openrouter.ai/settings/keys).
  4. 4In each model field (Gemini model, OpenAI model, Claude model), leave it on Automatic (recommended) — WinZapp switches on its own to the latest recommended model whenever the provider retires an old one. Only pick a specific model from the list if you want to pin that model anyway.
  5. 5Check which types you want processed: audio, images, videos, stickers and/or PDFs. Each has its own checkbox, independent of the others.
⚠️ At least one key is required
Without any valid API key configured (Gemini, OpenAI or Claude), WinZapp warns you and won't let you turn on AI features.
ℹ️ Not every provider handles video and audio
Video is only processed by Gemini — the other two providers don't accept video files. Audio is processed by Gemini and OpenAI; Claude doesn't transcribe audio. Image, sticker and PDF work with all three.

How to use it

With the feature on for the right media type, focusing a matching message (photo, audio, sticker, video or PDF) and pressing Tab shows a button — Describe or Transcribe, depending on the type. The same button is also available in the message's context menu. The result appears in its own window, with the text ready to be read by a screen reader or copied.

The same Describe button also appears when viewing an image or video status/story (Status tab), next to Save as... — same rule: it only disappears if no AI provider is configured.

💡 Stickers with text
Sticker and image descriptions already include any text visible in the media itself — handy for memes and stickers with captions.

📞 5. Calls

WinZapp announces incoming voice and video calls — from a contact or a group — saying who's calling ("So-and-so is calling you." or "Incoming group call in group X.").

Incoming call window

If the option is on (Settings > Conversations tab > Calls button > Open a window when receiving a call), a window appears with two buttons: Hang up and Close window. Closing the window doesn't hang up the call — it just dismisses the alert, the call keeps ringing on the phone.

ℹ️ The call itself happens on the phone
WinZapp announces and lets you decline an incoming call, but answering/talking is still done on the phone itself — WinZapp has no built-in call audio/video.

You can turn off call alerts entirely by unchecking Allow incoming call alerts in the same settings.

⚙️ 6. Settings

Reach Settings from the main menu (press Alt, go down to Settings and enter with the right arrow, then WinZapp Settings), or with the Ctrl+, shortcut. The window is organized into six tabs; some hold several related topics behind buttons, which open in their own window.

🌐 General

Language, spell check, and the Interface button (WinZapp's own visual interface preferences).

🦯 Accessibility

Screen reader preferences, and the Spoken content button (what's announced out loud and when).

🔌 Connection

Address and port of the local WPPConnect server, and reconnection options.

💾 Storage

Automatic media download (which types, how many days, maximum size), where/how to save files, and the Media cleanup and Backup buttons.

💬 Conversations

Four buttons: Locked conversations (lock code), Transcriptions and Descriptions (AI), Audio playback and Calls.

🔊 Sounds

Two buttons: Audio settings (input/output device) and Event sounds (which sound plays for each event — message, call, etc.).

WhatsApp Settings

This is a separate window — Settings > WhatsApp Settings, in the main menu — because these options live on your WhatsApp account itself, not in WinZapp. It has two ready tabs:

👤 Profile

About and profile photo — two independent fields. Fill in only what you want to change (or choose a photo); a blank field isn't changed.

🔒 Privacy

Last seen, online, about, photo, read receipts and who can add me to groups. Reading and saving both work normally; if a specific field can't be saved, WinZapp shows exactly which one it was.

Setting the locked-chats code

Inside Conversations, the Locked conversations button opens the tab where the code is set. If there's no code configured yet, just type the new code and confirm it. If a code already exists, you need to enter the current code before typing a new one — without that, whoever opened this window could change someone else's code without ever having known the original.

⚠️ Forgot the code?
There's no way to recover or reset the code without erasing what it protected. The only way to use the feature again is to disconnect the account (main menu > File > Disconnect) and pair again — this permanently deletes all of WinZapp's messages and media for this account and clears the way to set a new code. Chats locked from the phone itself aren't affected: they stay under the phone's control and go back to showing as locked in WinZapp as soon as the account resyncs.

Media cleanup

Inside Storage, the Media cleanup button deletes already-downloaded files to free up disk space — messages stay put, only the file disappears (it can be downloaded again later, if it's still available).

  1. 1Choose the chats: the list shows only ones already in your chats (regular and archived), identified by the contact/group name or, when there's no name, by the phone number. A filter lets you show all, only groups, or only individual chats, and the first item in the list, Select all, selects or clears everything the current filter is showing, all at once.
  2. 2Also choose the media types (photos, videos, audio, voice messages, documents) and, if you want, a minimum size in MB.
  3. 3Click Gather data — an overview appears: how many chats affected, how many files, and the total in MB, by type.
  4. 4Check the overview and click Proceed with cleanup to confirm, or close the window to cancel without deleting anything.
⚠️ Can't be undone
Deleting media files is permanent. The messages themselves are never affected — only the downloaded file.

Backup and restore

Inside Storage, the Backup button opens a window with two paths:

💾 Create backup

Choose which chats to include, which media types (photos, videos, audio, voice messages, documents) and, optionally, WinZapp's own settings. You can protect the file with a password.

♻️ Restore backup

Choose the file, type the password if it has one, and select what to restore — same logic for chats and media types.

In both cases, the chat list identifies each one by the contact/group name or, when there's no name, by the phone number; a filter lets you show all, only groups, or only individual chats; and the first item in the list, Select all, selects or clears everything the current filter is showing, all at once. When creating a backup, the list only shows chats that already appear in your chat lists (regular and archived) — no search is done across all contacts.

💡 Restoring never deletes anything
Restoring only adds what doesn't already exist in your account — no chat or message already present is overwritten or changed. You need to close and reopen WinZapp to see the restored content in the list.

👤 7. Accounts menu

The Accounts menu lives inside the main menu (press Alt, go down to Accounts and enter with the right arrow). It brings together everything related to the connected WhatsApp account:

🔀 Switch account

Every paired number is listed; selecting one switches to it. You can also switch quickly from the keyboard: Ctrl+Alt+1 through 9 jumps straight to the matching account, no matter where focus currently is.

⚙️ Manage accounts

Opens a window to add, rename, archive, restore or remove paired accounts.

📴 Offline mode

Pauses syncing with WhatsApp without actually disconnecting — handy for pausing the phone's data/battery use for a while.

🔌 Disconnect

Ends the current account's session; using it again requires pairing again.
